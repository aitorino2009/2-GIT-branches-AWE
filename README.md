# Práctica de Git: Branches y Git Graph

Este repositorio contiene la resolución completa de las tareas de aprendizaje interactivo de **Ramas (Branches) en Git** y **Git Graph en Visual Studio Code**.

## Documentación Completa de la Tarea

Puedes consultar el informe y resolución paso a paso en el archivo:
- [Tarea_Git_Branches_y_GitGraph.md](Tarea_Git_Branches_y_GitGraph.md)

## Estructura de Ramas del Repositorio

- `main`: Rama principal donde se integran los cambios validados y el merge commit con la resolución de conflictos.
- `nueva-idea`: Rama creada durante el Reto 2 y Reto 3 para experimentar cambios aislados (fusión Fast-forward).
- `feature-conflicto`: Rama auxiliar creada para simular y resolver un conflicto real de fusión (*Merge Conflict*).

## Visualización con Git Graph en VS Code

1. Instala la extensión **Git Graph** en VS Code.
2. Abre la vista de Git Graph desde la barra de estado inferior o la pestaña de Control de Código Fuente.
3. Observa el historial de commits, las ramificaciones y los puntos de fusión.
